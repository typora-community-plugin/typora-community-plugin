# 插件安装

插件可以装到两个位置：**全局**（所有笔记库共用）或**笔记库**（只对当前打开的文件夹生效）。

## 预览

![插件市场](../../assets/plugin-marketplace.jpg)

## 从插件市场安装

1. 启动 Typora。
2. 打开插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ [插件市场](./3e-plugin-marketplace.md)。
3. 在「搜索插件:」中输入插件名，找到目标插件。
4. 点击卡片上的安装按钮：
   - **全局**：安装到用户目录的 `.typora/community-plugins/plugins`。
   - **笔记库**：安装到当前笔记库的 `.typora/plugins`。
5. 安装成功后提示「插件 "{插件名}" 安装成功。」，卡片上的安装按钮消失。
6. 按下方「启用插件」勾选启用。

> 「笔记库」按钮只在当前笔记库使用[本地设置](./3-settings.md)时出现。只有「全局」按钮时，说明当前处于全局设置模式。

## 手动安装

适用于离线环境，或插件没有上架市场。

1. 关闭 Typora。
2. 下载插件压缩包。
3. 解压压缩包到插件目录：
   - 全局：用户目录的 `.typora/community-plugins/plugins/{插件id}`。
   - 笔记库：当前笔记库的 `.typora/plugins/{插件id}`。
4. 启动 Typora。
5. 启用插件。

> 解压后应直接看到 `manifest.json`，而不是多套一层文件夹。

## 启用插件

1. 打开插件配置对话框 → [已安装插件](./3f-installed-plugins.md)。
2. 勾选插件前面的复选框即可启用，取消勾选即禁用。
3. 启用后无需重启，插件声明的命令、面板和设置页会立即出现。

启用失败时会提示「插件 "{插件名}" 需要更高版本的 Typora Community Plugin。请检查更新。」，此时先[升级插件](./1c-update.md)。

## 更新插件

1. 打开插件配置对话框 → 已安装插件。
2. 该页会自动检查可更新版本，「已安装插件」旁的徽章显示可更新数量。
3. 有新版本的插件右侧出现「更新」按钮，点击即可升级。
4. 没有「更新」按钮，说明该插件已是最新版本。

更新成功提示「插件 "{插件名}" 更新成功。」；已是最新时提示「插件 "{插件名}" 已是最新版本。」。

## 卸载插件

1. 打开插件配置对话框 → 已安装插件。
2. 点击插件右侧的「卸载」按钮。

> 卸载**没有二次确认**，点击后立即移除插件目录（移入系统回收站），并对当前会话生效。插件的数据文件不会自动删除。

## 常见问题

| 现象 | 处理 |
|------|------|
| 下载失败，提示「下载失败。请稍后重试。或者尝试更换"Github 代理"。」 | 到[插件市场](./3e-plugin-marketplace.md)换一个 Github 代理后重试 |
| 「下载的插件 "{插件名}" id 与用户安装的 id 不相同。」 | 本地已存在同 id 插件且来源不一致，先在已安装插件中卸载旧版再装 |
| 市场列表一直是「插件列表（共 0 个）」 | 网络不可达，换代理或稍后重试；手动安装不受影响 |
| 启用后功能没出现 | 确认插件已被勾选；部分插件需要重启 Typora 或依赖其他插件（如[元数据](./3d-internal-plugins.md)） |

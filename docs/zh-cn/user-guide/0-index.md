## 阅读约定

- **快捷键**：文档中的 <kbd>Ctrl</kbd>+<kbd>.</kbd> 与 <kbd>F1</kbd> 是默认值，macOS 上同样是 <kbd>Ctrl</kbd>，不会自动变成 <kbd>Cmd</kbd>。可在 [快捷键设置](./3c-hotkey.md) 中改绑。
- **插件配置对话框**：指按下 <kbd>Ctrl</kbd>+<kbd>.</kbd> 打开的对话框，界面上有时也叫「插件设置」，两者是同一个窗口。
- **笔记库**：指当前在 Typora 中打开的文件夹。
- **版本标注**：少数功能需要较新版本，正文会以「需 v2.10.33+」的形式标注。

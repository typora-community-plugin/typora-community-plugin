# 右侧面板

编辑区右侧可以拉出一个独立侧栏，用来承载插件提供的辅助视图。核心本身不内置任何右侧视图，内容全部来自插件。

> 需 v2.10+。需要启用[工作区](./3d-internal-plugins.md)。

## 预览

![右侧面板](../../assets/user/right-panel.gif)

## 在哪里打开

状态栏右侧、「字数统计」左侧有一个「切换右侧面板」按钮（图标为右对齐线条）。点击即可展开或收起。

## 操作

| 操作 | 方式 |
|------|------|
| 展开 / 收起 | 点击状态栏「切换右侧面板」按钮 |
| 调整宽度 | 拖动面板左边缘的分隔条 |
| 自动折叠 | 宽度拖到约 50 像素以下时自动收起 |
| 恢复宽度 | 再次展开时回到上次的宽度，最小 280 像素 |
| 查看空面板 | 没有插件向右侧面板添加视图时，显示「此侧边栏为空。」 |

## 注意与限制

- 关闭[工作区](./3d-internal-plugins.md)后，状态栏的切换按钮消失，右侧面板不可用。
- 面板宽度会保存在当前生效的设置中；最小宽度固定为 280 像素，无法拖得更窄。
- 面板里能看到什么完全取决于已启用的插件。空白只有一行「此侧边栏为空。」，说明当前没有插件使用它，属正常现象。
- 右侧面板与左侧的活动栏 / 侧栏互不影响，可以同时展开。

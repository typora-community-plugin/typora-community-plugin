# 命令面板

按下 <kbd>F1</kbd> 打开命令面板，输入关键词即可搜索并执行插件提供的所有命令，不用记快捷键。

## 预览

![命令面板](../../assets/command-palette.jpg)

## 打开方式

- 按下 <kbd>F1</kbd>。
- 插件也可以在自己的界面里调用「打开命令面板」，效果相同。

## 操作

| 操作 | 方式 |
|------|------|
| 过滤命令 | 直接在输入框中输入文字，占位文案为「输入文本过滤命令」 |
| 移动选中项 | <kbd>↑</kbd> / <kbd>↓</kbd> |
| 执行命令 | <kbd>Enter</kbd>，或鼠标单击 |
| 关闭面板 | <kbd>Esc</kbd>，或点击面板外部 |

## 列表结构

- **最近使用**：最多 5 条最近执行过的命令，按执行时间倒序。
- **其他命令**：其余全部可用命令。

命令名会带上插件名前缀，例如 `Tag: 打开标签面板`，用来区分不同插件的同名命令。

## 常见用法

**不记快捷键执行命令**

按下 <kbd>F1</kbd>，输入「本地设置」，选中「使用本地设置 (添加 `.typora` 到本地)」回车，即可把当前笔记库切换为本地设置。详见[设置总览](./3-settings.md)。

**找某个插件的全部命令**

输入插件名（如 `Tag`），列表会只剩该插件提供的命令。

## 注意与限制

- 少数内部命令不会出现在列表中（例如「打开命令面板」自身，以及插件未声明为可见的命令）。
- 未启用的插件，其命令不会出现在列表里。
- 命令列表在插件启用/停用后立即更新，不需要重启。
- 「最近使用」保存在 Typora 的本地存储中，不随设置模式变化。

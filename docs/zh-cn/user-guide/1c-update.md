# 升级插件

Typora Community Plugin 可以自己下载并替换自身文件，不需要重新走一遍安装脚本。

## 预览

![关于页更新入口](../../assets/user/settings-about.jpg)

## 在哪里升级

插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ [关于](./3g-about.md) → 点击「更新」。

## 手动升级

1. 打开插件配置对话框 → 关于，确认当前版本号。
2. 点击「更新」。
3. 等待下载完成，界面提示「Typora Community Plugin 更新成功。(需要重启 Typora)」。
4. 重启 Typora。

已是最新版本时提示「Typora Community Plugin 已是最新版本。」，不会重复下载。

## 自动检查更新

「关于」页的「自动检查更新」默认开启。开启后，每次启动 Typora 并首次打开插件配置对话框时会检查一次：

- 有新版本：侧栏「关于」旁显示 `New` 徽章，页面标题旁显示「有更新」。
- 无新版本：不显示任何提示。
- 关闭该选项后不再自动检查，徽章也会一并消失；此时仍可手动点击「更新」。

## 查看更新内容

「关于」页的「更新日志」按钮会下载并展开本仓库的 `CHANGELOG.md`：

- 首次点击显示「加载中…」，加载完成后按钮变为「收起」。
- 仓库中没有更新日志时提示「未在本仓库找到更新日志。」。
- 更新日志内容需要联网获取；离线时点开会是空白，可改为查看 [CHANGELOG](./CHANGELOG.md)。

## 注意与限制

- 升级只替换插件系统自身文件。**社区插件不会跟着升级**，需要到 [已安装插件](./3f-installed-plugins.md) 中单独更新。
- 下载走 Github，网络受限时可能失败。可先在 [插件市场](./3e-plugin-marketplace.md) 中换一个「Github 代理」再重试。
- 升级完成后必须**重启 Typora**，否则运行的仍是旧版本。

# 插件市场

浏览、搜索并安装社区插件。列表数据来自项目维护的插件发布仓库，需要联网。

## 预览

![插件市场](../../assets/plugin-marketplace.jpg)

## 在哪里打开

插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ 插件市场。每次切到该页都会自动重新加载列表。

## 设置项

| 设置项 | 默认值 | 作用 | 备注 |
|--------|--------|------|------|
| 下载器 | `Typora`（macOS 为 `CLI`） | 选择下载插件包的方式：`Typora` 更稳定、错误提示更少；`Nodejs` 会显示更详细的错误信息 | 该选项只在 Windows / Linux 上出现 |
| Github 代理 | `github`（直连） | 加载插件列表与下载插件时使用的代理 | 可选 `gh-proxy.com`、`gh-proxy.org`、`ghproxy.net`、`ghproxy.homeboyc.cn`；直连失败时换一个 |
| 搜索插件: | 空 | 按插件名称和描述过滤卡片，忽略大小写 | 输入后约 0.5 秒生效 |
| 插件列表（共 {0} 个） | — | 标题右侧三个按钮：时钟=按更新时间排序（从近到远）、下载图标=按下载量排序（从多到少）、刷新=重新加载插件列表 | 排序按钮再次点击可取消排序，回到默认顺序 |

## 插件卡片

| 元素 | 说明 |
|------|------|
| 名称、作者、描述 | 插件基本信息 |
| `Repository` | 点击跳转到插件源码仓库 |
| 最后更新、大小、下载次数 | 仅在获取到统计数据时显示 |
| `OS:` 平台图标 | 标明插件支持的平台 |
| 「介绍」 | 下载并展开该仓库的 `README.md`，加载时显示「加载中…」，展开后按钮变为「收起」 |
| 「全局」 | 安装到全局插件目录，所有笔记库可用 |
| 「笔记库」 | 安装到当前笔记库的 `.typora/plugins`，只在当前使用本地设置时出现 |

安装成功后提示「插件 "{插件名}" 安装成功。」，该卡片的安装按钮随即消失。**安装完成不会自动启用**，需到[已安装插件](./3f-installed-plugins.md)勾选。

## 常见用法

**列表一直为空**

1. 确认能访问 Github。
2. 把「Github 代理」换成 `gh-proxy.com` 或 `ghproxy.net`。
3. 点击「重新加载插件列表」。

**只想在某个笔记库用某插件**

1. 先让该笔记库使用[本地设置](./3-settings.md)（命令面板执行「使用本地设置」）。
2. 回到插件市场，卡片上会出现「笔记库」按钮。

## 注意与限制

- 列表与统计来自网络，离线时「插件列表（共 0 个）」，不显示错误原因。
- 代理设置失效时会提示「Github 代理失效，已自动恢复为默认设置。」，并自动切回 `github`。
- 下载失败提示「下载失败。请稍后重试。或者尝试更换"Github 代理"。」；使用 `Nodejs` 下载器时会给出英文错误详情。
- 「介绍」内容需要单独联网获取，切换代理后会清空已缓存的内容。
- 市场没有「安装本地 zip」入口，离线安装请走[手动安装](./2-plugin-installation.md)。

# 快捷键设置

为插件命令绑定键盘快捷键。插件安装后，它注册的命令会自动出现在这一页。

## 预览

![快捷键设置](../../assets/user/settings-hotkey.jpg)

## 在哪里打开

插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ 快捷键。也可以按 <kbd>F1</kbd> 打开[命令面板](./6-command-palette.md)，执行「打开插件配置对话框」后切换到「快捷键」。

## 操作步骤

### 查找命令

在「搜索命令」框中输入命令名，列表会按名称过滤（约 300 毫秒后生效）。命令名会带上插件名前缀，例如 `Tag: 某某命令`。

### 添加快捷键

1. 找到尚未绑定快捷键的命令，点击命令右侧的 <span class="fa fa-plus primary"></span> 按钮。
2. 按钮文字变为「请按下快捷键...」。
3. 按下想绑定的组合键，例如 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>。
4. 按键松开后立即生效，并显示为可移除的标签。

### 移除快捷键

点击快捷键标签右侧的 <kbd>×</kbd> 图标。移除后该命令重新显示 <span class="fa fa-plus primary"></span> 按钮，可重新绑定。

## 快捷键格式

快捷键以 `+` 连接修饰键和主键，例如 `Ctrl+Shift+K`。系统会自动归一化大小写与修饰键别名：

| 输入 | 归一化后（Windows / Linux） | 归一化后（macOS） |
|------|------------------------------|--------------------|
| `ctrl+k` | `Ctrl+K` | `Ctrl+K` |
| `meta+k`、`command+k`、`cmd+k` | `Win+K` | `Cmd+K` |
| `alt+k`、`option+k` | `Alt+K` | `Opt+K` |
| `ctrl+shift+left` | `Ctrl+Shift+←` | `Ctrl+Shift+←` |

## 注意与限制

- 列表中只显示**会在命令面板中出现**的命令；少数内部命令无法绑定快捷键。
- 同一时间只修改一个命令的绑定：正在捕获按键时按其他键不会顺带修改别的命令。
- 命令有两种作用域，由插件自行定义：**全局**（Typora 任意区域按下都生效）和**编辑器**（焦点在编辑区内才生效）。
- 默认快捷键在 macOS 上同样是 <kbd>Ctrl</kbd>+<kbd>.</kbd> 与 <kbd>F1</kbd>，不会自动变成 <kbd>Cmd</kbd>；只有你自定义使用 `meta`/`cmd` 时才会显示为 `Cmd`。
- 绑定结果保存在当前生效的设置中（全局或本地）。切换设置模式后需要重新绑定。

## 附：用户可见命令清单

| 命令 | 默认快捷键 | 作用 |
|------|------------|------|
| 打开命令面板 | <kbd>F1</kbd> | 搜索并执行命令（本身不出现在命令面板列表中） |
| 打开插件配置对话框 | <kbd>Ctrl</kbd>+<kbd>.</kbd> | 打开本页所在对话框 |
| 使用本地设置 (添加 `.typora` 到本地) | 无 | 复制全局设置到笔记库并切换，仅在使用全局设置时出现 |
| 使用全局设置 (从本地删除 `.typora`) | 无 | 删除笔记库的本地设置，仅在使用本地设置时出现 |
| Workspace: 右侧打开窗格 | 无 | 左右分屏，需启用[工作区](./4a-workspace.md) |
| Workspace: 下方打开窗格 | 无 | 上下分屏 |
| Workspace: 重置 | 无 | 清除分屏，恢复单窗格 |
| Notice: 关闭所有提示信息 | 无 | 一次性关闭右下角全部提示框 |

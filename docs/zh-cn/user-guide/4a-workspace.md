# 工作区（Workspace）

工作区把 Typora 的单文档编辑区改造成**多标签 + 分屏 + 预览窗格**的布局，类似浏览器的标签页。

## 预览

![workspace](../../assets/user/workspace.jpg)

## 在哪里打开

工作区是内置插件，默认启用。打开文件后，编辑器上方即出现文件标签页。

- 停用/启用：插件配置对话框 → [内置插件](./3d-internal-plugins.md) → 「工作区」。
- 关闭标签页功能、隐藏扩展名等：插件配置对话框 → 内置插件设置 → [工作区设置](#工作区设置)。

## 使用

### 文件标签页

| 操作 | 方式 |
|------|------|
| 切换文件 | 左键单击标签 |
| 关闭标签 | 点击标签右侧的 <kbd>×</kbd>，或**中键单击**标签 |
| 关闭多个 | 右键标签 →「关闭标签」/「关闭其他标签」/「关闭右侧标签」 |
| 调整顺序 | 按住标签拖动，可在同一窗格内重排，也可拖到另一个窗格 |
| 浏览溢出标签 | 在标签栏上滚动鼠标滚轮，标签栏横向滚动 |
| 查看完整路径 | 鼠标悬停在标签上，提示中显示相对笔记库的路径 |

标签名过长时会截断并显示 `…`。未保存的新文件标签显示为 `Untitled`（英文原文）。

### 分屏

| 操作 | 方式 |
|------|------|
| 左右分屏 | 命令面板执行「Workspace: 右侧打开窗格」 |
| 上下分屏 | 命令面板执行「Workspace: 下方打开窗格」 |
| 在右侧打开文件 | 文件树中右键文件 →「在右侧打开」，或标签右键 →「右侧打开」 |
| 在下方打开文件 | 标签右键 →「下方打开」 |
| 退出分屏 | 命令面板执行「Workspace: 重置」 |
| 调整窗格大小 | 拖动窗格之间的分隔条 |

> 标签右键菜单里的「右侧打开」「下方打开」只在当前窗格有 2 个以上标签时出现。

### Markdown 预览窗格

分屏后可以把一侧当作只读预览：

- 预览窗格用渲染后的 Markdown 显示内容，标题栏图标与编辑器标签不同（实心文档图标）。
- 单击预览区域，会与当前编辑器**互换**：预览变为可编辑，原编辑区变为预览。
- 该行为由「单击预览区域时切换编辑器和预览」控制，默认开启；关闭后单击预览不再切换。

### 空标签页

新建标签页且没有打开文件时，页面显示「无打开文件」，并列出当前可用的快捷键（打开命令面板、打开应用设置、打开插件配置对话框）。

- 默认显示该提示页；勾选「显示空白 New Tab」后改为完全空白页。
- 新标签页的标题为 `New tab`（英文原文）。

## 工作区设置

插件配置对话框 → 内置插件设置 → 工作区。

| 设置项 | 默认值 | 作用 | 备注 |
|--------|--------|------|------|
| 使用文件标签页 | 开启 | 在主编辑器区域以标签页形式打开文件 | 关闭后无标签栏，也不能切换/关闭标签 |
| 隐藏文件标签的文件扩展名 | 关闭 | 标签上的 `File.md` 显示为 `File` | 只影响标签显示，不改文件名 |
| 显示空白 New Tab | 关闭 | 新建标签页时显示空白页，而不是「无打开文件」提示 | — |
| 单击预览区域时切换编辑器和预览 | 开启 | 单击预览窗格把它变为编辑器，同时把原编辑器变为预览 | 关闭后预览为纯只读 |
| 启用音频查看 | 开启 | 用内置查看器打开音频文件 | 详见[文件查看器](./4e-file-views.md) |
| 启用视频查看 | 开启 | 用内置查看器打开视频文件 | 同上 |
| 启用图片查看 | 开启 | 用内置查看器打开图片文件 | 同上 |

## 注意与限制

- 强烈建议在 Typora 的「应用设置 → 通用」中开启「切换文件时自动保存对上一个文件的更改」，否则切换标签时未保存的修改需要手动保存。
- 工作区停用后，标签页、分屏、预览窗格与[右侧面板](./4d-right-panel.md)一起消失，恢复为 Typora 原生编辑器。
- 未保存文件标签名为英文 `Untitled`、新标签页为 `New tab`，不随界面语言变化。

# 内置插件

内置插件随插件系统一起安装，不需要从市场下载。这里只有一个开关页：勾选即启用，取消即停用。

## 预览

![内置插件](../../assets/user/settings-internal-plugins.jpg)

## 在哪里打开

插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ 内置插件。

## 设置项

| 设置项 | 默认值 | 作用 | 备注 |
|--------|--------|------|------|
| 元数据 (测试版) | 关闭 | 为笔记库中所有文件建立元数据索引，供标签、标题、文件名等结构化搜索和其他插件使用 | 首次开启会全量索引，期间状态栏显示 `Indexing: 已完成/总数`；关闭后索引缓存被清空 |
| 工作区 | 开启 | 提供文件标签页、分屏、Markdown 预览窗格、右侧面板和状态栏开关 | 关闭后标签页与分屏消失，「工作区」设置页也从侧栏移除 |

## 使用元数据（测试版）

1. 在「内置插件」中勾选「元数据 (测试版)」。
2. 状态栏右侧出现 `Indexing: 0/120` 形式的进度（数字为已完成数和总数），索引期间可以正常编辑。
3. 进度消失表示索引完成，此后[高级搜索](./4c-advanced-search.md)的结构化查询才能返回结果。
4. 索引结果会缓存，下次启动直接复用；文件保存、重命名、删除时会增量更新。

> 索引状态栏文字为英文 `Indexing:`，这是插件的原始文案，不是语言设置没生效。

## 使用工作区

工作区默认开启。停用后：

- 编辑器恢复为 Typora 原生单文档模式，文件标签页、分屏、预览窗格全部消失。
- 状态栏的「切换右侧面板」按钮消失，[右侧面板](./4d-right-panel.md)不可用。
- 设置侧栏的「工作区」页一并移除；再次勾选后恢复，之前的标签页状态不会保留。

## 注意与限制

- 元数据索引只覆盖 Markdown 与图片两类文件；其他文件即使出现在文件树里也不会被结构化搜索命中。
- 索引期间磁盘和 CPU 占用会上升，笔记库很大时建议在空闲时开启，完成后保持开启即可。
- 工作区停用不影响已安装的社区插件，但依赖标签页或右侧面板的插件功能会随之中断。

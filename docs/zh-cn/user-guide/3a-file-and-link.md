# 文件与链接

控制 Markdown 链接如何打开，以及「快速打开面板」里显示哪些文件。主要用于配合[文件标签页](./4a-workspace.md)使用。

## 预览

![文件与链接设置](../../assets/settings-modal.jpg)

## 在哪里打开

插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ 文件与链接。

## 设置项

| 设置项 | 默认值 | 作用 | 备注 |
|--------|--------|------|------|
| 在当前窗口打开 Markdown 超链接 | 开启 | 按住 <kbd>Ctrl</kbd>（macOS 为 <kbd>⌘</kbd>）单击 Markdown 超链接时，在当前窗口内打开，而不是新开一个 Typora 窗口 | 使用文件标签页时建议开启 |
| 无后缀 Markdown 超链接 | 关闭 | 链接没有写扩展名时自动补 `.md`，例如 `[Note](note)` 会打开 `note.md` | 只影响相对路径链接 |
| 在当前窗口快速打开文件 | 开启 | 在 Typora 原生的快速打开面板中选中文件时，在当前窗口打开，并记录到「最近打开」 | 使用文件标签页时建议开启 |
| 在快速打开面板中排除指定文件夹 | 开启 | 勾选后按右侧输入框的规则，把匹配文件夹中的文件从快速打开面板中隐藏 | 输入框默认值 `.git`；多个文件夹用逗号分隔，路径相对笔记库 |

## 常见用法

**让链接在当前窗口的标签页里打开**

1. 勾选「在当前窗口打开 Markdown 超链接」。
2. 按住 <kbd>Ctrl</kbd> 单击笔记中的相对链接，目标文件会在新标签页打开。
3. 不按 <kbd>Ctrl</kbd> 直接单击，仍交给 Typora 原生行为处理。

**隐藏 `.git`、`node_modules` 等目录**

1. 勾选「在快速打开面板中排除指定文件夹」。
2. 在输入框中填写 `.git, node_modules, dist`。
3. 重新打开快速打开面板，这些目录下的文件不再出现。

## 注意与限制

- 排除规则只影响**快速打开面板**，不影响文件树、搜索和标签页。
- 无后缀链接补全只对 Markdown 相对链接生效；`http(s)://` 链接与自定义协议链接（如 `vscode://`）不受影响。
- 链接指向的文件不存在时不会弹出提示，仅记录到日志。

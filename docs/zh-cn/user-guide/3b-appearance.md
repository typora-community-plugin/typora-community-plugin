# 外观

控制文件树显示范围、搜索面板行为，以及是否显示活动栏。

## 预览

![外观设置](../../assets/user/settings-appearance.jpg)

## 在哪里打开

插件配置对话框（<kbd>Ctrl</kbd>+<kbd>.</kbd>）→ 外观。

## 设置项

| 设置项 | 默认值 | 作用 | 备注 |
|--------|--------|------|------|
| 显示不支持的文件 | 关闭 | 在文件树中也列出图片、音视频、压缩包等非 Markdown 文件；打开时用系统默认程序打开 | 关闭时文件树只显示支持的文本类文件 |
| 保留搜索结果 | 关闭 | 从搜索面板切到「文件管理」等其他面板后再切回，搜索结果不丢失 | 关闭时切走即清空 |
| 显示搜索结果完整路径 | 关闭 | 鼠标悬停在搜索结果的文件路径上时，以提示形式显示完整路径 | 仅在搜索面板生效 |
| 高级搜索模式 | 关闭 | 用自定义搜索引擎替换 Typora 原生搜索，支持 `tag:`、布尔组合等语法 | 开启后搜索框上方出现「搜索 / 高级搜索」切换行，详见[高级搜索](./4c-advanced-search.md) |
| 显示活动栏 | 开启 | 显示左侧[活动栏](./4b-ribbon.md)，同时启用自定义侧边面板 | 关闭后活动栏整体消失，仍可用 <kbd>F1</kbd> 和 <kbd>Ctrl</kbd>+<kbd>.</kbd> |

## 常见用法

**临时关掉活动栏**

插件配置对话框 → 外观 → 高级选项 → 取消勾选「显示活动栏」。重新勾选后无需重启即可恢复。

**只搜 Markdown 正文，不要图片和杂项**

保持「显示不支持的文件」关闭状态。

## 注意与限制

- 高级搜索模式不支持正则表达式，`/foo/` 会被当作普通字符搜索。详见[高级搜索的限制](./4c-advanced-search.md#注意与限制)。
- 「显示不支持的文件」会让文件树变长；笔记库里文件很多时建议保持关闭。
- 「保留搜索结果」只是让面板切换时不主动清空，不涉及搜索内容的保存。

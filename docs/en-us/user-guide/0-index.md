Pick an entry point by scenario: the first group if you are just getting started, the second for daily use, and the third for specific options.

## Conventions

- **Shortcuts**: <kbd>Ctrl</kbd>+<kbd>.</kbd> and <kbd>F1</kbd> in this guide are the defaults. On macOS they are still <kbd>Ctrl</kbd> and do not automatically become <kbd>Cmd</kbd>. You can rebind them in [Hotkey settings](./3c-hotkey.md).
- **Plugin Settings modal**: the dialog opened with <kbd>Ctrl</kbd>+<kbd>.</kbd>. The UI sometimes calls it "plugin settings"; both refer to the same window.
- **Vault**: the folder currently opened in Typora.
- **Version notes**: a few features require a newer version; the text marks them as "requires v2.10.33+".
